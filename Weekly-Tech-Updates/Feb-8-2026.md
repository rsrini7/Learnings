### Claude Opus 4.6 (February 5, 2026)
Anthropic released Claude Opus 4.6, marking a significant advancement in agentic coding and professional workflows.

- **Context Compaction**: Automatically summarizes long conversations to maintain coherence
- **Fast Mode** (research preview): Up to 2.5x faster output token generation at premium pricing

**Performance:**
- **Terminal-Bench 2.0**: 65.4% (highest score ever recorded)
- **GDPval-AA**: 1606 Elo (144 points ahead of GPT-5.2)
- **MRCR v2** (long-context retrieval): 76% vs 18.5% for Sonnet 4.5
- **Finance Agent benchmark**: #1 ranking for financial analyst tasks

**Integration & Availability:**
- Available immediately via claude.ai, API, and major cloud platforms (AWS, Google Cloud)
- Integrated into GitHub Copilot for Pro, Pro+, Business, and Enterprise users
- PowerPoint integration (preview): Claude as accessible side panel for presentation creation
- Pricing: $5/$25 per 1M tokens (input/output)

**Security Achievement:**
- Discovered **500+ previously unknown high-severity vulnerabilities** in open-source libraries
- Found zero-day vulnerabilities in GhostScript, OpenSC, and CGIF without specialized tools
- Strongest safety profile in industry with extensive evaluation pipeline

### Forcing Agents to Use Skills
Solutions to prevent AI agents from ignoring custom skills/rules:

**Solution 1: agents.md file**
- Agents read automatically
- Central location for agent instructions

**Solution 2: Persistent context instructions**
- Tell agent exactly when/how to trigger skills

**Solution 3: Compressed Reference**
- Acts as map for LLM to find detailed docs
- Stored within project structure

**Solution 4: Leveled approach**
- Embed primary rules directly via index
- Use pointers for secondary skills
- Avoids context bloat

**Solution 5: Proactive prompting**
- Force-trigger specific skills when needed
