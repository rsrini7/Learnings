# Weekly AI & Tech Updates – March 29, 2026

## 🚀 Core Model & Algorithm Advances

### Google TurboQuant for Extreme LLM Compression (Mar 22–29, 2026)
- **TurboQuant** compresses the KV cache of large language models down to as little as 3 bits while keeping benchmark behavior essentially unchanged. 
- Targets the main inference bottleneck: GPU memory for long‑context attention, shrinking memory use by ≈6x. 
- On Nvidia H100s, 4‑bit TurboQuant delivers up to **8x** speedup for attention logits versus standard 32‑bit keys. 

### Xiaomi MiMo‑V2‑Pro Foundation Model (Released Mar 18, 2026)
- MiMo‑V2‑Pro is a Mixture‑of‑Experts model with **1T+ total** parameters and 42B active, exposed via API. 
- Supports **1M‑token** context; API pricing is $1/$3 per 1M in/out tokens up to 256K, and $2/$6 from 256K–1M. 
- Benchmarks place it between Kimi K2.5 and GLM‑5 overall, with coding performance reportedly surpassing Claude 4.6 Sonnet. 
- Smaller MiMo‑V2‑Flash ships with open weights under the MIT license. 

### Google Gemini 3.1 Ultra & Usage Milestones (Late Mar 2026)
- Gemini 3.1 Ultra adds **native multimodal reasoning** with a **2M‑token** context window. 
- Gemini has reached **750M active users**, and users can now import ChatGPT chat history. 
- Integrated into Google TV for visual help, deep dives, and sports briefs; Google is exploring in‑UI ads as AI answers cannibalize search traffic. 

### Moonshot AI “Attention Residuals” (Mar 22–29, 2026)
- New **Attention Residuals** mechanism lets each transformer layer attend over the history of prior layers instead of only summing residual streams. 
- This helps recover early‑layer features that otherwise get buried as depth grows, enabling layers to selectively query past representations via depth‑wise attention. 

### DeepSeek Engram: Conditional Transformer Memory (Late Feb–Mar 2026, covered Mar 27)
- **Engram** is a conditional memory block that sits alongside attention and feedforward layers. 
- It acts like a learned lookup table for common multi‑token patterns, using hash‑based retrieval with contextual gating. 
- Experiments show models reach final predictions earlier in the network, effectively adding functional depth without increasing layer count.

### Deep Agent & Automation Ecosystem (Mar 27, 2026)

#### Anthropic Claude Code Channels
- Claude Code Channels expose Claude via Telegram/Discord using an MCP‑based bridge between messaging apps and an active Claude Code session. 
- Messages from chat are pushed as events into Claude; responses can trigger tools, run tests, and reply back through the same thread. 
- Official Telegram plugin can be installed and configured via `/plugin install telegram@claude-plugins-official` and `claude --channels plugin:telegram@claude-plugins-official`. 

#### Claude Cowork Projects
- **Projects** are persistent workspaces with their own files, memory, instructions, skills, and scheduled tasks. 
- Example: a YouTube content project where Claude remembers brand voice, upload cadence, and runs ongoing competitor analysis. 
- Combined with memory and app connectors, Projects now cover ~90% of one power user’s prior OpenClaw use cases with lower security risk. 

#### Claude Computer Use & Remote Control
- Claude’s computer‑use mode controls keyboard and mouse via rapid screenshots, operating like a human user on your desktop. 
- Main browsers (Chrome, Safari, Firefox, Edge) are partially restricted for outreach‑style actions; using **Min Browser** avoids those blocklists and gives full read/write automation. 
- This human‑like interaction helps bypass typical bot detection on platforms like LinkedIn, Instagram, and Facebook while still allowing manual user intervention. 

#### Dispatch + Remote Phone Control (Mar 22–29, 2026)

## 🧬 Security, Supply Chain & Safety

### LiteLLM / LiteLLM Compromise (Mar 24, 2026)

#### PyPI Backdoor Incident (Mar 22–29, 2026)
- On March 24, attackers briefly shipped two backdoored `litellm` versions (1.82.7 and 1.82.8) to PyPI, turning the widely used AI gateway into a credential‑stealer. 
- The compromise lasted ~46 minutes before PyPI quarantined the project. 
- Malicious additions (e.g., in `proxy_server.py` and `.pth` auto‑loader) executed on install/import and aggressively searched for secrets. 

#### Broader Compromise Details (Mar 27, 2026)
- A group linked to LAPSUS$, TeamPCP, injected code into Python wheels used by **LiteLLM**, which normalizes multiple LLM APIs into an OpenAI‑compatible interface and sees 95M+ monthly downloads. 
- The payload installed a hidden `systemd` backdoor (`sysmon.service`) that persisted across reboots and polled attacker servers for further instructions. 
- Guidance includes checking `uv pip show litellm`, searching caches for malicious wheels, and inspecting `~/.config/sysmon/sysmon.py` plus related files. 

### Anthropic vs. US Government Injunction (Mar 24–25, 2026)
- On March 24 a federal judge in San Francisco heard Anthropic’s challenge to a Pentagon “supply chain risk” blacklist and a presidential directive banning federal agencies from using Claude. 
- On March 25, Judge Rita Lin issued a 43‑page preliminary injunction blocking the Trump administration’s directive and halting the Pentagon designation, calling the notion of labeling a dissenting US company an “enemy and saboteur” unsupported by statute. 
- The ruling is stayed for one week to allow a Department of Justice appeal.
