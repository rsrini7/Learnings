## 🔒 Security & Safety

### Moltbot Security Disaster ($16M Crypto Scam)

**Background**: Moltbot (originally Clawdbot)
- Open-source local personal AI assistant
- Written in TypeScript
- Combines Claude Code with persistent memory
- Connects WhatsApp, Telegram, Slack, Discord, Signal, iMessage, emails, calendars, cameras, smart-home devices
- Created by Peter Steinberger (Vienna/London)

**Name Change** (January 27, 2026):
- Changed from ClawdBot to Moltbot
- Original name based on "Clawd" (Claude Code mascot)
- Anthropic owned the trademark
- "Molt" = lobster theme reference

**Security Incident** (72 hours):

1. **Handle Sniping**:
   - During rebrand, old GitHub and social identities briefly released
   - Automated "handle snipers" grabbed old Clawdbot handle on X and GitHub
   - Posted crypto wallet addresses implying "official" token
   - **Token was never official** - creator never endorsed it

2. **Crypto Scam**:
   - Traders assumed early, sanctioned AI-related coin
   - When denial hit and liquidity pulled, late entrants were rugged
   - Anonymous token creators walked away with large profits
   - **$16M total scam value**

3. **Exposed Control Panels**:
   - Security researchers found **hundreds of exposed Moltbot/Clawdbot control panels**
   - Often with **no authentication**
   - Leaked: API keys, OAuth tokens, conversation histories
   - Some allowed unauthenticated command execution on host system

**Root Cause**:
- Not zero-day in code
- Widespread bad deployments:
  - Trusting localhost
  - Misconfigured reverse proxies
- Given Moltbot's broad system access = high-impact incident

**Timeline**: ~3 days from GitHub popularity → trademark C&D → rebrand → handle sniping → token launches → mass security scanning

## 🔬 Research & Breakthroughs

### Skills v1.1.1 - Agent Support Issues

**Problem**: Agents not invoking (ignoring) skills

**Root Cause**:
- Most frontier models not yet fully trained on using skills vs standard tool usage
- Adding skills sometimes performed **worse than baseline**

**Solution - Alternative Approach**:
- Use **"agents.md" or "clode.md" file** to house grounding information
- Instead of autonomous skill invocation, stuff summarized documentation directly into grounding files
- **Compress context**: 40KB → 8KB
- Mitigates "context rot"
- Ensures agent follows necessary instructions

**References**:
- https://github.com/vercel-labs/skills
- http://www.youtube.com/watch?v=A_1ELXEVp5w

### RAG Reasoning Collapse

**Discovery**: 2026 study from EPFL and Stony Brook

**Problem**: 
- Occurs when RAG systems provide information conflicting with LLM's pre-trained internal memory
- Models frequently fail to propagate new information through complex reasoning chains
- Internal parametric knowledge often overrides external context
- Causes hallucination or reversion to outdated facts during multi-step tasks

**Impact**:
- Particularly problematic in coding/technical fields where logic is intertwined with specific data
- Current RAG techniques fragile for mission-critical applications

**Proposed Solution**:
- Move beyond simple retrieval
- Advanced fine-tuning and post-training methods
- Effectively "overwrite" LLM's fundamental beliefs

**Reference**: https://www.youtube.com/watch?v=BmzdS-a-G8g

### Google Gemini 3 Flash - Agentic Vision

**Core Mechanism** (Think-Act-Observe Loop):
1. **Think**: Plans steps based on query and image
2. **Act**: Runs Python to crop, zoom, annotate, or calculate (e.g., count objects precisely)
3. **Observe**: Feeds modified image back for refined reasoning

**Innovation**: Turns static image analysis into active, agentic process with Python code execution

## 📊 Platform Stats & History

### Git & GitHub Evolution

**Git Creation**:
- Created by Linus Torvalds in **April 2005**
- Development time: **5-10 days**
- Motivation: Licensing dispute with BitKeeper

**GitHub**:
- Founded: 2007
- Launched: April 2008
- **Microsoft acquisition**: October 26, 2018 for **$7.5 Billion**

**Growth Metrics**:
- At acquisition: 28M developers
- As of 2025: **150M+ developers**
- **1 Billion+ repositories**

**Revenue**:
- 2024 ARR: **$2 Billion**
- Estimated valuation: **$16-18 Billion** or more

**GitHub Copilot**:
- Accounts for **40%+ of GitHub revenue growth**
- Larger business than all of GitHub at time of acquisition
