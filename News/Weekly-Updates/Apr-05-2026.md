# Weekly AI \& Tech Updates – April 05, 2026

***

## 🚨 Major Agent \& Platform Shifts

### Anthropic Claude Code Source Leak (March 31–April 1, 2026)

- Anthropic accidentally exposed the full Claude Code internal source via a misconfigured `.npmignore` in an npm package, leaking ~500k lines across ~2,000 files that were forked tens of thousands of times within hours.
- The company confirmed no customer data was exposed and framed it as human error rather than a classic security breach, but broad GitHub takedowns initially removed many more repos than intended before being narrowed.
- Post‑leak analysis shows Claude Code is a sophisticated prompt‑orchestrated agent stack with 11+ internal stages, anti‑distillation “poison pills,” frustration detection, agent “Buddy” modes, and rich permission/summary systems powering its reliability.


### Anthropic “Conway” Persistent Agent

- Anthropic is testing an internal “Conway” sidebar agent that persists across sessions, exposes a `.cnw.zip` ecosystem for tools/UI bundles, and integrates tightly with Claude Code and browser control.
- Conway supports webhooks for event‑driven workflows (true “run in the background” automation) and signals a shift from chat assistant to always‑on, multi‑step enterprise agent.


### Microsoft 365 Becomes Agentic

- Microsoft has quietly turned Excel, Teams, and SharePoint into agentic surfaces where Copilot can take multi‑step actions using context from emails, meetings, and files without separate cloud workflows.
- Teams now auto‑generates narrated highlight reels in multiple languages, and Copilot can remember prior decisions across tasks, effectively introducing persistent agent memory into Office.


### Salesforce Slackbot as Meta‑Agent

- Slackbot is now an MCP client that can route work across 6,000+ apps and agents, turning Slack into a control plane rather than just chat.
- Reusable “skills” let a single user define workflows that then run for the whole org without re‑prompting, standardizing agent usage across teams.


### Apple Opens Siri to Multiple Models (Announced for iOS 27)

- Apple is ending ChatGPT’s exclusive Siri integration by launching an “Extensions” system in iOS 27 where installed AI apps (Claude, Gemini, ChatGPT, etc.) can answer Siri requests per‑task.
- Apple will take a 30% cut of AI subscriptions sold via the App Store, turning Siri into an open AI marketplace and a new high‑margin revenue line, with announcement expected at WWDC on June 8, 2026.

## 🧠 Benchmarks, Models \& World Models

### ARC‑AGI‑3 Interactive Reasoning Benchmark (March 25, 2026)

- ARC‑AGI‑3 is a new interactive benchmark where agents must discover rules and objectives by exploring hundreds of game‑like environments without instructions; humans score 100% while frontier models are below 1%.[^3]
- Early scores include Gemini Pro ~0.37%, GPT‑5.4 High ~0.26%, Anthropic Opus 4.6 ~0.25%, and Grok‑4.20 effectively 0%, demonstrating a huge gap between current LLMs and general agentic intelligence.[^4]


### LM Arena \& Coding Model Rankings (Data as of March 31, 2026)

- Community “LM Arena” leaderboards show coding‑focused top models clustered around ELO 1490–1550, led by Claude Opus 4.6 (thinking variants), Gemini 3.x Pro/Flash, GPT‑5.4 High, and Grok 4.20 variants.
- On open side, very large models such as DeepSeek V3.2 (671B), Ernie 5.0 (2.4T), GLM‑5.0 (744B), Kimi K2.5 Thinking (~1T), Qwen 3.5 (397B), and Xiaomi MiMo‑V2‑Pro (1T+) dominate web‑arena and web‑agent leaderboards.


### Google Gemma 4 Open Models (April 1–2, 2026)

- Google released **Gemma 4**, a fully open‑source model family (Apache 2.0) in four sizes: E2B (≈2.3B), E4B (≈4.5B), 26B MoE (~4B active), and 31B dense, targeting reasoning, coding, and agentic workflows on edge and server.[^5][^6]
- Gemma 4 runs locally on Android phones, laptops, and small servers, supports multimodal input (text, images, video, audio on edge), and offers up to 128K–256K context windows while ranking near the top of open‑model leaderboards.[^6]


### LeWorldModel (LeWM) – Tiny World Model for Robotics

- LeWM, a 15M‑parameter video‑based world model from LeCun and collaborators, learns directly from raw pixels without pre‑trained encoders and plans 48× faster than DINO‑WM while using ~200× fewer tokens.
- It outperforms larger models on robotics tasks like pushing and cube manipulation, trains in hours on a consumer GPU, and fits into LeCun’s JEPA‑based bet (via AMI Labs’ \$1B+ funding) that grounded world models will beat extreme LLM scaling.


### GLM 5.1 \& GLM‑5V‑Turbo by Z.ai

- GLM 5.1 is a frontier‑class coding and agentic model reported as competitive with Claude Opus 4.6 but cheaper and more generous in usage, available via API with open‑source weights planned.
- GLM‑5V‑Turbo targets vision‑centric agent tasks with a ~200K context window and state‑of‑the‑art scores on GUI benchmarks like AndroidWorld and WebVoyager, optimized for screenshot‑to‑code and UI‑automation workflows.


### EVO 2 – DNA Foundation Model

- EVO 2 from Stanford and Arc Institute is trained on ~9 trillion DNA bases, handling sequences of up to 1M nucleotides and achieving clinical‑grade accuracy on BRCA cancer‑linked mutations despite no explicit medical training.
- The model can also synthesize functional DNA, such as mitochondrial genomes, and is framed as a “ChatGPT moment” for biology, enabling advances in personalized medicine, agriculture, and synthetic biology.

## 🛠 Agent Architectures, Tools \& Infrastructure

### Claude Code: Agent Design \& Feature Wave

- Anthropic disclosed that Claude Code’s strength comes from a 3‑agent loop (Planner, Generator, Evaluator) where a skeptical evaluator breaks typical LLM self‑praise and forces real self‑correction.
- New features across v2.1.79–2.1.89 include: Computer Use on Mac, teleport between devices, remote control, session forking, Git worktrees, hooks, effort levels, /loop, /btw side threads, and detailed security/permission controls.


### Claude Code Execution \& Agent SDK

- “Computer Use” (March 23) allows Claude Code to control Mac screens directly, and the Claude Agent SDK lets developers wire local terminals, schedulers, and tools into Claude as an execution agent using npm and Python APIs.
- The stack combines a local CLI, SDK, and Anthropic API so agents can spawn subprocesses, run scripts, and orchestrate long‑running work with hooks and policies around dangerous operations.


### Cloudflare Dynamic Workers for AI Code (March 23–24, 2026)

- Cloudflare released **Dynamic Workers**, an isolate‑based runtime that spins up ephemeral V8 sandboxes for AI‑generated code ~100× faster and 10–100× more memory‑efficient than containers.[^7][^8]
- The platform pushes a “code mode” pattern where agents write TypeScript functions against APIs instead of issuing many tool calls, reportedly cutting token usage and enabling fine‑grained security via outbound request interception and auto‑scanning.[^8][^7]


### Cloudflare LLM Security Agent for Skimming Attacks

- Cloudflare also launched an LLM‑powered agent that scans 3.5B+ scripts per day to catch malicious JavaScript (like keyloggers) before they touch user data, upgrading an enterprise‑tier feature to all self‑serve customers for free.
- A notable case is a keylogger on a major U.S. bank’s store, illustrating why real‑time semantic code analysis is becoming mandatory for large web properties.


### IBM Granite 4.0 Vision for Document Agents

- IBM’s Granite 4.0 Vision is a 3B modular vision model that selectively activates vision to convert charts, tables, and complex documents into structured JSON/HTML/code for agent pipelines.
- It ranks near the top of the VAREX leaderboard for 2–4B models (~85.5% exact‑match, zero‑shot) and is released under Apache 2.0, enabling enterprise reuse without licensing friction.


### Mistral Forge – Custom Enterprise Models

- Mistral launched **Forge**, a platform for training fully custom models on proprietary data, positioned as “not just fine‑tuning or RAG” but domain‑specific bases for enterprise agents.
- Early adopters include Ericsson, ESA, and ASML, reflecting demand for sovereign performance, data control, and lower dependence on generic frontier models.

## 🧩 Training Algorithms, Compression \& Infra Research

### EGGROLL Training Algorithm

- EGGROLL replaces gradient descent with a low‑rank evolution‑strategy scheme: it perturbs weights using LoRA‑style directions and keeps improvements, making sampling ~1M variants almost as cheap as a single forward pass.
- Because the method is non‑differentiable, it supports native int8 training and non‑differentiable architectures (discrete memory, neurosymbolic systems), though results so far are on relatively small models.


### Google TurboQuant Vector Compression

- Google’s TurboQuant compresses KV cache from 32‑bit to roughly 3–4 bits with no retraining, achieving up to 6× memory reduction and up to 8× attention‑layer speedup with negligible accuracy loss.[^7]
- It combines PolarQuant (geometry re‑parameterization) and QJL (sign‑bit correction) and can accelerate both LLM inference and generic vector search, enough to spook memory‑chip investors on fears of lower demand.

## 🤖 Consumer \& Enterprise Agent Products

### Google: Agentic Safety \& Gmail AI Inbox

- Google published a new view of “reasonable” AI safety, arguing that with 300× efficiency gains in two years, models are no longer just predictors but actors and must meet expectations for “Personal Intelligence” that is proactive but controllable.
- Gmail’s AI Inbox now acts as a personal agent that reads mail, proposes to‑dos, clusters low‑priority updates into topics, and automatically surfaces VIPs using Gemini 3 while keeping training boundaries around user data.


### Shopify Tinker – Brand Identity Agent

- Shopify launched **Tinker**, a free AI agent that uses 100+ tools across OpenAI, Google, and Anthropic to generate full brand visual identities from natural descriptions.
- It maintains brand consistency across sessions without re‑prompting, effectively shifting product discovery from keyword search to visually/contextually driven agent recommendations.


### Alibaba Accio Work – E‑commerce Agent Squad

- Accio Work is an enterprise no‑code platform that deploys coordinated agents for market research, product sourcing, storefront design, marketing, and logistics, promising a fully operational online store in under 30 minutes.
- Powered by Alibaba’s trade data, it supports autonomous supplier negotiations and VAT compliance in 100+ markets while requiring explicit approval for high‑risk actions, targeting founders and SMBs.


### AutoClaw \& Ollama Pi – Local Agent Stacks

- AutoClaw by Z.ai is a “one‑click” local agent that uses GLM‑5 Turbo (744B/40B MoE) to automate Chrome, run deep research, and orchestrate content campaigns on a standard PC.
- Ollama’s **Pi** is a lightweight coding agent harness with built‑in primitives, sub‑agents, and an “autoresearch” loop; it can run both local and cloud models (e.g., `ollama launch pi --model kimi-k2.5:cloud`) and powers OpenClaw.


### RealRestorer – AI Photo Restoration

- RealRestorer is an open‑source image model that restores damaged, noisy, or black‑and‑white photos and benchmarks near top closed models, though it currently requires high‑end CUDA GPUs.


### InstaDoodle – Animated Presentations

- InstaDoodle offers cloud‑based, whiteboard‑style animated presentations, turning topics or scripts into narrated doodle videos in 40+ languages with royalty‑free soundtracks, starting around \$47/month.


### Suno v5.5 – Text‑to‑Music

- Suno’s v5.5 release improves voice control, introduces custom models and a “My Taste” feature that adapts generations to user preferences, while enforcing voice‑ownership verification to limit misuse.

## 🧩 Agent Frameworks, Skills \& Developer Ecosystem

### Claude Data Analyst Plugin

- Anthropic shipped a Data Analyst plugin with slash commands like `/analyze`, `/write-query`, `/create-viz`, and `/build-dashboard`, plus skills for SQL best practices, statistical analysis, and dashboard building.
- The plugin aims to turn Claude into a full analyst agent: profiling data, generating optimized SQL, producing publication‑grade visuals, and validating analyses before sharing.


### Trace2Skill – Automated Skill Extraction (Qwen)

- Qwen’s Trace2Skill converts execution traces into reusable markdown skills using 128 parallel sub‑agents, reportedly outperforming manually written skills (including Anthropic’s) and transferring from larger (122B) to smaller models.
- The work argues that real environmental interaction, not just parametric knowledge, is essential for robust skill formation in agents.


### Open‑Source Repos Around Claude Code

- Five highlighted repos expand Claude Code: Auto Research (self‑improvement loops), OpenSpace (skill health monitor), CLI Anything (wrap any repo as a CLI tool), Claude Peers (multi‑terminal collaboration), and a Google Workspace CLI connector.
- Together they push Claude Code toward multi‑agent, self‑optimizing “development environments” rather than a single coding assistant.


### Autonomous Agent Systems \& Toolkits

- Four notable autonomous projects: GStack (role‑based multi‑agent stack with “Office Hours”), Hermes Agent (self‑improving OS), Superpowers (professional‑workflow plugins), and Paperclip (attempting “zero‑human” companies).
- Garry Tan’s Claude Code Toolkit adds YC‑style office hours, CEO review, design consultation, engineering review, and doc‑release skills, making VC‑grade product critique and planning available as repeatable workflows.

## 📈 Jobs, Layoffs \& the Engineer’s Role

### AI‑Linked Layoffs \& Reallocation

- Tech layoff trackers show ~41.5K US tech layoffs in 2026 YTD and ~90K globally across roles, down from ~246K in 2025 but still significant.
- Oracle alone laid off ~25K employees explicitly citing AI, reallocating an estimated \$8–10B toward a ~\$156B AI infra build‑out; Dell cut ~11K (~10% of staff) with clear AI links.


### “Good Engineering Has Not Got Cheaper”

- A widely shared essay argues that while code generation is cheap, enterprise‑grade engineering remains costly because bottlenecks moved to planning, alignment, architecture, QA, and security.
- Teams must now invest 2–5× more upfront clarity (requirements, edge cases, “definition of done”), and re‑think QA to cover logic, regressions, and maintainability in AI‑written codebases.
